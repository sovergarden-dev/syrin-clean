Install Syrin clean from the complete ZIP. Run install.ps1 with Windows PowerShell 5.1, or ask your agent to do so (add -IncludeDetectedAgents or -AgentTargets to also install into detected .codex, .cursor or .gemini\antigravity skill roots). The installer checks the manifest, stages target locations and retains previous versions as backups. Start a new agent session after installation. No system cleanup is performed by the installer. This is a development build; read the support matrix before using mutation features.
