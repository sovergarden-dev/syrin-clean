# Try the preview

[Open the example report](https://sovergarden-dev.github.io/syrin-clean/report-demo.html) · [Web app and downloads](https://sovergarden-dev.github.io/syrin-clean/) · [Q&A](https://github.com/sovergarden-dev/syrin-clean/discussions/categories/q-a)

## English

The example report is a browser-only demonstration built from synthetic data. It does not describe your computer, scan folders or execute file operations. The current preview still has the [qualification limits](../feat/support.md) listed in the support matrix.

1. Open the report and read the yellow example-data banner. Switch **Language** between English and Tiếng Việt; the controls update in place.
2. Review **At a glance**. Values marked **Not measured** remain unknown; they are not zero and do not prove that the computer is healthy. Folder sizes are not a promise of reclaimable space.
3. Open **File operation history**, type `sample-001` in **Find a file**, and select the example item `Q1`.
4. Select **Prepare restore request**. The text starts with **This is a synthetic example. Do not execute it.** This prepares an example request, not a restore operation. Do not run the example paths or IDs against a real machine.

For a first real audit, follow the [installation steps](../../README.md#start-with-an-audit), then ask your agent: **Audit this PC and prepare proposals only. Do not move, delete or change anything.** Review the results and support boundaries before authorizing a separate file plan. The browser demo does not install or run the Windows runtime.

Use [Q&A](https://github.com/sovergarden-dev/syrin-clean/discussions/categories/q-a) for usage questions and [Issues](https://github.com/sovergarden-dev/syrin-clean/issues) for reproducible defects. English and Vietnamese are welcome. Include the version, Windows build/architecture, agent or browser used, steps, expected result and actual result. Replace personal paths with placeholders; remove tokens, private links and account details. Do not upload raw session directories or complete machine reports without reviewing their contents.

## Tiếng Việt

[Báo cáo mẫu](https://sovergarden-dev.github.io/syrin-clean/report-demo.html) chạy trong trình duyệt với dữ liệu giả. Nó không mô tả máy của bạn, không quét thư mục và không thực thi thao tác file. Bản preview vẫn còn các [giới hạn kiểm chứng](../feat/support.md).

1. Mở báo cáo, đọc nhãn dữ liệu minh họa màu vàng và chọn **Tiếng Việt** trong ô **Language**. Các nút và nhãn được đổi ngay trên trang.
2. Xem **Tổng quan**. **Chưa đo** không có nghĩa là bằng 0 hay máy không có lỗi. Dung lượng thư mục cũng không phải cam kết dung lượng sẽ thu hồi.
3. Mở **Lịch sử thao tác file**, nhập `sample-001` vào **Tìm file**, rồi chọn mục minh họa `Q1`.
4. Bấm **Tạo yêu cầu khôi phục**. Nội dung bắt đầu bằng **Đây là ví dụ giả lập. Không thực thi.** Đây chỉ là yêu cầu minh họa, không phải thao tác khôi phục. Không dùng đường dẫn hoặc ID mẫu để chạy trên máy thật.

Để kiểm tra máy lần đầu, làm theo [hướng dẫn cài đặt](../../README.vi.md), rồi yêu cầu agent: **Chỉ kiểm tra máy và lập đề xuất. Không di chuyển, xóa hoặc thay đổi gì.** Xem kết quả và giới hạn hỗ trợ trước khi duyệt một kế hoạch thao tác file riêng. Demo trên trình duyệt không cài hay chạy runtime Windows.

Đặt câu hỏi sử dụng tại [Q&A](https://github.com/sovergarden-dev/syrin-clean/discussions/categories/q-a), báo lỗi có bước tái hiện tại [Issues](https://github.com/sovergarden-dev/syrin-clean/issues). Có thể viết tiếng Việt hoặc tiếng Anh. Gửi phiên bản, Windows/kiến trúc máy, agent hoặc trình duyệt, các bước, kết quả mong đợi và thực tế. Thay đường dẫn cá nhân bằng ví dụ; bỏ token, link riêng tư và thông tin tài khoản. Xem kỹ nội dung trước khi chia sẻ báo cáo máy; không tải nguyên thư mục phiên làm việc lên công khai.
