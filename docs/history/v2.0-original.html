2. Ma trận Thích ứng Phần cứng (Hardware-Agnostic Decision Matrix)

        

          Điểm nâng cấp cốt lõi của bản Universal v2.0: Thay vì áp dụng một lời khuyên cố định cho mọi máy, prompt buộc AI Agent phải phân nhánh khuyến nghị dựa trên thông số thực tế đo được ở Giai đoạn 0:
        

        

          

            
              

                Tiêu chí phát hiện
                Trường hợp A
                Trường hợp B
                Trường hợp C
              

            
            
              

                Loại máy (Form Factor)
Win32_SystemEnclosure / Pin		
                Máy bàn (Desktop - Không pin):
Gợi ý thu gọn hoặc tắt Hibernate (powercfg /hibernate off hoặc /type reduced) để lấy lại 6–25 GB ổ C:. Chế độ nguồn ưu tiên Balanced hoặc High Performance.		
                Laptop / Handheld PC (Có pin):
TUYỆT ĐỐI KHÔNG tắt Hibernate (tránh mất dữ liệu khi hết pin/gập máy); chỉ gợi ý /type reduced nếu ổ C: quá chật. Phân tách cấu hình nguồn khi cắm sạc (AC) và dùng pin (DC).		
                Máy ảo (VM / Cloud PC):
Bỏ qua kiểm tra nhiệt độ vật lý, SMART, BIOS và Hibernation; tập trung vào tiến trình nền, dịch vụ và thu gọn ổ ảo.		
              

              

                Dung lượng RAM
Win32_PhysicalMemory		
                RAM thấp (≤ 8 GB):
Khắt khe tối đa với Startup apps, trình duyệt chạy nền (Edge/Chrome Startup Boost), Widget, hiệu ứng trong suốt. Đảm bảo Pagefile = System Managed trên ổ SSD nhanh nhất.		
                RAM tầm trung (12 – 16 GB):
Tắt Startup không cần thiết; giữ nguyên SysMain (Superfetch) trên SSD; kiểm tra Memory Compression và Hard Page Faults khi mở đa nhiệm.		
                RAM lớn (≥ 32 GB):
Hiệu ứng hình ảnh và SysMain không gây nghẽn. Tập trung vào tốc độ Bus RAM thực tế (kiểm tra xem người dùng có quên bật XMP/DOCP/EXPO trong BIOS không) và dung lượng hiberfil.sys lớn.		
              

              

                Loại ổ đĩa hệ thống
Get-PhysicalDisk		
                NVMe / SATA SSD:
Kiểm tra TRIM (DisableDeleteNotify = 0), giữ trống ≥15–20% (hoặc ≥30 GB) để bộ điều khiển SSD thực hiện Garbage Collection & Wear Leveling. Không bao giờ defrag truyền thống.		
                Ổ cơ HDD làm ổ C::
Báo động đỏ: đây là nút cổ chai số 1. Kiểm tra mức phân mảnh, giữ SysMain để đệm vào RAM, giảm tối đa các tác vụ ghi log/index ngầm cùng lúc, và khuyên nâng cấp SSD.		
                Thiết lập đa ổ đĩa (C: + D:/E:):
Ưu tiên di chuyển thư viện Steam/Epic, biến môi trường cache (HuggingFace/pip/npm), thư mục Video/Capture và WSL2 VHDX từ ổ C: sang ổ phụ thay vì xóa.		
              

              

                Hệ sinh thái CPU & GPU
Win32_Processor / VideoController		
                NVIDIA GPU:
Kiểm tra NVDisplay.Container, dọn gói cài cũ ở C:\NVIDIA & Downloader, kiểm tra DXCache/GLCache.		
                AMD Ryzen / Radeon:
Kiểm tra gói giải nén thừa ở C:\AMD (thường chiếm 2–10 GB sau mỗi lần cập nhật Adrenalin), kiểm tra AMD Chipset Driver.		
                Intel Core (Hybrid P/E-core) / iGPU:
Với Intel Gen 12+ (P-core + E-core), khuyên dùng Windows 11 + chế độ nguồn Balanced để Thread Director điều phối nhân chuẩn nhất (High Performance cũ có thể làm kẹt xung/sai nhân).

                Nhóm đối tượng
                Vị trí / Thủ phạm ẩn
                Dung lượng thường gặp
                Cách xử lý chuẩn an toàn trong Prompt v2.0

                  • AI Models: .cache\huggingface, .ollama\models

                  • Với cache quản lý gói: Dùng lệnh chính chủ (npm cache clean --force, pip cache purge, docker builder prune) sau khi bạn duyệt.

4. Vì sao máy chậm? — Thứ tự chẩn đoán chuẩn trên mọi cấu hình

        

          Dựa trên tài liệu hiệu năng chính thức của Microsoft và thực tế kỹ thuật hệ thống, Agent được lập trình để kiểm tra các nguyên nhân theo thứ tự tác động thực tế cao nhất:
        

        

          

            
              
#Nguyên nhân gốc rễCách Agent phát hiện bằng số liệu (Giai đoạn 0)Hiệu quả thực tế sau khi xử lý

            
            
              

                1
                Quá tải App khởi động, Dịch vụ ngoài & Tác vụ chạy nền
(Launcher, Updater, Chat, Trình duyệt chạy ngầm, Overlay)		
                Đếm số mục trong Startup (Registry Run + Startup Folder + Task Scheduler Logon) và tổng RAM/CPU bị chiếm ngay sau khi đăng nhập.
                Rất cao trên mọi máy (đặc biệt máy ≤16 GB RAM). Tắt (Disable) hoàn tác được 100%.
              

              

                2
                Nghẽn ổ đĩa hệ thống (HDD làm ổ C: hoặc SSD bị đầy >85–90%)
                Đo MediaType, % dung lượng trống ổ C:, độ trễ đọc/ghi (Avg. Disk sec/Transfer) và hàng đợi đĩa.
                Rất cao nếu ổ C: đang đỏ hoặc là HDD. Giải phóng về ngưỡng ≥15–20% (hoặc ≥30 GB) giúp SSD phục hồi tốc độ ghi.
              

              

                3
                Một tiến trình "nổi loạn", rò rỉ bộ nhớ (Memory Leak) hoặc lỗi hệ thống lặp lại
                Chụp Top 10 tiến trình theo CPU / Working Set / Commit Size / IOPS đĩa + Quét Windows Event Viewer (System/Application Critical & Error trong 7 ngày).
                Cao — bắt trúng thủ phạm gây giật cục thay vì tối ưu mù quáng.
              

              

                4
                Quá nhiệt (Thermal Throttling) hoặc giới hạn nguồn điện (Power Limit / Power Saver)
                Kiểm tra cảm biến nhiệt độ, xung nhịp thực tế của CPU so với Base/Boost clock, và Power Plan hiện tại (tránh kẹt ở Power Saver hoặc xung nhịp thấp).
                Cao nếu đang bị bóp xung do nhiệt hoặc sai Power Plan.
              

              

                5
                Cấu hình phần cứng chạy dưới sức (RAM chưa bật XMP/EXPO, GPU chạy sai card, Driver lỗi)
                So sánh ConfiguredClockSpeed của RAM (VD: đang chạy 2133/4800 MHz thay vì 3200/6000 MHz), kiểm tra phiên bản Driver GPU/Chipset và trạng thái HAGS.
                Trung bình – Cao (Bật XMP/EXPO trong BIOS hoặc sửa đúng GPU rời cho app/game tăng 10–30% hiệu năng).
              

              

                6
                Thiếu RAM vật lý dẫn đến tràn sang Pagefile (Swapping liên tục)
                Đo tỷ lệ Commit Charge / Tổng RAM và chỉ số Memory\Pages/sec (Hard Page Faults).
                Cao trên máy 4–8 GB RAM (hoặc 16 GB mở nhiều tab/IDE). Xử lý bằng cách giảm app nền + tối ưu Pagefile trên SSD nhanh nhất.
              

              

                7
                Tồn đọng Windows Update, lỗi file hệ thống (SFC/DISM) hoặc Search Indexer bị kẹt
                Kiểm tra cờ PendingReboot, lịch sử Windows Update lỗi, kích thước Windows.edb của Search Indexer và DISM /CheckHealth.
                Trung bình – Cao về độ ổn định, hết tình trạng quạt rú ngầm vô cớ.
              

            
          

        

      


      

        
5. Phân loại: An toàn / Thận trọng / Tuyệt đối không đụng

        
Bảng quy chuẩn an toàn được nhúng trực tiếp vào luật cứng của Prompt v2.0:

        

          

            
Hạng mục can thiệpPhân loạiQuy tắc xử lý trong Prompt v2.0

            
              

                File tạm %TEMP%, C:\Windows\Temp (bỏ qua file đang mở trong 24h hoặc đang khóa)
                Nhóm A/B — An toàn
                Tự tái tạo khi cần, không chứa dữ liệu người dùng.
              

              

                Delivery Optimization, Thumbnail Cache, DirectX Shader Cache, Cache trình duyệt (chỉ Cache)
                Nhóm B — An toàn
                Tự dựng lại. Riêng Shader Cache có ghi chú: game có thể biên dịch lại shader ở lần mở đầu tiên.
              

              

                Thư mục bộ cài giải nén thừa: C:\NVIDIA, C:\AMD, C:\SWSetup, C:\Drivers
                Nhóm B — An toàn
                Chỉ là bản giải nén tạm khi cài driver, xóa đi giải phóng 2–15 GB mà không ảnh hưởng driver đang chạy.
              

              

                Thu gọn ổ ảo WSL2 / Docker (Optimize-VHD / compact vdisk)
                Nhóm B — An toàn
                Chỉ thu hồi vùng trống đã xóa bên trong file .vhdx, không làm mất bất kỳ file hay container nào.
              

              

                Tắt (Disable) app khởi động cùng Windows & tác vụ Updater không thiết yếu
                Nhóm A — An toàn
                Chỉ Disable (không Delete/Uninstall), hoàn tác lại bằng 1 lệnh hoặc 1 cú click.
              

              

                Bộ đệm lập trình (npm, pip, uv, NuGet, Gradle, Cargo)
                Nhóm B — An toàn
                Dùng lệnh purge chính thức của từng công cụ; chỉ phải tải lại gói khi build project mới.
              

              

                Windows.old, Windows Update Cleanup (StartComponentCleanup)
                Nhóm C — Thận trọng
                Giải phóng 5–35 GB nhưng mất khả năng quay về bản Windows/Update cũ. Chỉ gợi ý khi máy đang chạy ổn định.
              

              

                Dọn Thùng rác (Recycle Bin), thư mục Downloads, Videos\Captures
                Nhóm C — Thận trọng
                Phải liệt kê Top 10–20 file lớn nhất kèm ngày sửa để bạn duyệt đích danh từng mục.
              

              

                Cache ứng dụng nhắn tin & đồ họa (Zalo, Telegram, Adobe Media Cache, CapCut)
                Nhóm C — Thận trọng
                Đo dung lượng thật và hướng dẫn dọn qua công cụ nội bộ của app hoặc xóa thư mục cache media khi đã đóng app.
              

              

                Tùy chỉnh hiberfil.sys (/type reduced hoặc /hibernate off)
                Nhóm C — Thận trọng
                Tự động phân nhánh: chỉ gợi ý off trên Desktop không dùng Hibernate; trên Laptop chỉ cho phép giữ nguyên hoặc reduced.
              

              

                Cập nhật Driver (GPU/Chipset) & Tinh chỉnh Pagefile / Restore Point Max Size
                Nhóm C — Thận trọng
                Chỉ dùng nguồn chính hãng (Windows Update, NVIDIA, AMD, Intel, OEM); tạo Restore Point trước khi làm.
              

              

                Xóa tay System32, WinSxS, DriverStore, C:\Windows\Installer, phân vùng EFI/Recovery
                Nhóm D — Cấm tuyệt đối
                Làm hỏng Windows, mất khả năng gỡ/cập nhật phần mềm MSI hoặc mất khả năng khởi động.
              

              

                Xóa toàn bộ AppData, Save Game, Cookie/Mật khẩu trình duyệt, SSH/GPG Keys (.ssh), .env
                Nhóm D — Cấm tuyệt đối
                Mất dữ liệu cá nhân, mất tài khoản, mất khóa bảo mật hoặc mất tiến trình chơi game không thể khôi phục.
              

              

                Chạy script debloat từ mạng (irm ... | iex), phần mềm dọn Registry, RAM Booster, tắt Defender/Windows Update/Firewall
                Nhóm D — Cấm tuyệt đối
                Nguy cơ mã độc, lỗi hệ điều hành ngầm sau cập nhật và không mang lại lợi ích hiệu năng thực tế.
              

            
          

        

      


      

        
6. Giải mã các "Huyền thoại Tối ưu Windows"

        

          

            
Lời đồn phổ biếnSự thật kỹ thuật & Cách xử lý trong Prompt v2.0

            
              

                "Xóa thư mục C:\Windows\Prefetch giúp máy nhanh hơn"
                Sai — làm chậm lần mở app tiếp theo. Prefetch lưu bản đồ đọc trước của ứng dụng, tự giới hạn 1.024 file (~15–30 MB). Xóa đi buộc Windows tốn CPU/Disk dựng lại từ đầu.
              

              

                "Phải tắt dịch vụ SysMain (Superfetch) trên mọi máy"
                Không đúng cho đa số máy. SysMain tận dụng RAM trống để nạp sẵn app hay dùng và nhả RAM ngay lập tức khi cần. Chỉ thử tạm dừng (Stop) nếu đo thấy chính tiến trình SysMain gây 100% Disk kéo dài trên ổ đời cũ.
              

              

                "Xóa thư mục C:\Windows\Installer để lấy lại vài chục GB"
                Cực kỳ nguy hiểm. Dù thư mục này có thể nặng 5–30 GB, việc xóa tay sẽ làm các phần mềm cài bằng MSI (Office, Visual Studio, Adobe, v.v.) không thể cập nhật hoặc gỡ cài đặt được nữa.
              

              

                "Dọn Registry hằng tuần giúp Windows mượt hơn"
                Huyền thoại + Rủi ro cao. Các khóa Registry mồ côi chỉ nặng vài KB và Windows không quét toàn bộ Registry vào RAM theo cách làm chậm máy. Xóa nhầm khóa COM/Shell/Driver có thể gây lỗi app hoặc màn hình xanh.
              

              

                "Tắt Pagefile (đặt = 0) khi máy có 16–32 GB RAM trở lên"
                Sai lầm. Nhiều game, trình biên dịch, công cụ AI và cả hệ thống ghi Crash Dump của Windows yêu cầu Commit Charge qua Pagefile ngay cả khi RAM vật lý còn trống. Đặt Pagefile = 0 dễ gây văng app (Out of Memory) đột ngột.
              

              

                "Dùng lệnh Get-CimInstance Win32_Product để liệt kê phần mềm"
                Bẫy kỹ thuật kinh điển. Truy vấn lớp WMI Win32_Product kích hoạt Windows Installer kiểm tra tính toàn vẹn và tự sửa chữa (self-repair) lại toàn bộ gói MSI trên máy — vừa cực chậm vừa có thể làm hỏng cấu hình app.
              

            
          

        

      


      

        
7. Bộ lệnh PowerShell Kiểm toán Chỉ-Đọc v2.0 (Chống treo, Chống lặp Symlink)

        

          Nếu bạn muốn tự chạy kiểm tra nhanh trên PowerShell trước khi dùng Agent, bộ lệnh v2.0 dưới đây đã được tối ưu hóa để chạy xong trong vài giây (không bị kẹt ở WinSxS hay vòng lặp Symbolic Link như các lệnh đệ quy thông thường):
        

        

          

            PowerShell — Kiểm toán Hệ thống & Dung lượng Nhanh (100% Read-Only)
            
          

          
# 1. Kiểm tra quyền Admin, Loại máy (Desktop/Laptop), CPU, RAM (kèm tốc độ Bus thực tế) & GPU
$isAdmin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
Write-Host "Dang chay quyen Admin: $isAdmin" -ForegroundColor Cyan
Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model, PCSystemType, @{n='TotalRAM_GB';e={[math]::Round($_.TotalPhysicalMemory/1GB,1)}}
Get-CimInstance Win32_PhysicalMemory | Select-Object BankLabel, @{n='SizeGB';e={$_.Capacity/1GB}}, Speed, ConfiguredClockSpeed
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors, MaxClockSpeed
Get-CimInstance Win32_VideoController | Select-Object Name, DriverVersion, DriverDate

# 2. Kiểm tra Ổ đĩa vật lý (SSD/HDD/NVMe, Sức khỏe) & Dung lượng trống các phân vùng
Get-PhysicalDisk | Select-Object FriendlyName, MediaType, BusType, HealthStatus, @{n='SizeGB';e={[math]::Round($_.Size/1GB,1)}}
Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" | Select-Object DeviceID, VolumeName,
  @{n='SizeGB';e={[math]::Round($_.Size/1GB,1)}},
  @{n='FreeGB';e={[math]::Round($_.FreeSpace/1GB,1)}},
  @{n='FreePct';e={[math]::Round(($_.FreeSpace/$_.Size)*100,1)}}

# 3. Quét nhanh các "Kho Rác & Bộ Đệm Ẩn" phổ biến (Chống lặp ReparsePoint/Symlink)
$radarPaths = @{
  "User_Temp"          = "$env:TEMP"
  "Windows_Temp"       = "C:\Windows\Temp"
  "SoftwareDist_DL"    = "C:\Windows\SoftwareDistribution\Download"
  "NVIDIA_D3DCache"    = "$env:LOCALAPPDATA\NVIDIA\DXCache"
  "AMD_DxCache"        = "$env:LOCALAPPDATA\AMD\DxCache"
  "NVIDIA_Extracted"   = "C:\NVIDIA"
  "AMD_Extracted"      = "C:\AMD"
  "CrashDumps_Local"   = "$env:LOCALAPPDATA\CrashDumps"
  "Windows_Minidump"   = "C:\Windows\Minidump"
  "Windows_Old"        = "C:\Windows.old"
  "Zalo_AppData"       = "$env:LOCALAPPDATA\ZaloPC"
  "Telegram_Data"      = "$env:APPDATA\Telegram Desktop\tdata"
  "Adobe_MediaCache"   = "$env:APPDATA\Adobe\Common\Media Cache Files"
  "CapCut_Cache"       = "$env:LOCALAPPDATA\CapCut\User Data\Cache"
  "NPM_Cache"          = "$env:LOCALAPPDATA\npm-cache"
  "Pip_Cache"          = "$env:LOCALAPPDATA\pip\Cache"
  "HuggingFace_Cache"  = "$env:USERPROFILE\.cache\huggingface"
  "Docker_WSL_Data"    = "$env:LOCALAPPDATA\Docker\wsl"
}
$radarPaths.GetEnumerator() | ForEach-Object {
  if (Test-Path $_.Value) {
    $bytes = (Get-ChildItem $_.Value -Recurse -Force -File -Attributes !ReparsePoint -ErrorAction SilentlyContinue | Measure-Object Length -Sum).Sum
    if ($bytes -gt 10MB) {
      [PSCustomObject]@{ Category = $_.Key; Path = $_.Value; Size_GB = [math]::Round($bytes/1GB, 2); Size_MB = [math]::Round($bytes/1MB, 0) }
    }
  }
} | Sort-Object Size_GB -Descending | Format-Table -AutoSize

# 4. Tìm mọi file ổ ảo (.vhdx của WSL2/Docker/Hyper-V) và file lớn nhất (>500MB) trong User Profile
Get-ChildItem $env:USERPROFILE -Recurse -Force -File -Attributes !ReparsePoint -ErrorAction SilentlyContinue |
  Where-Object { $_.Length -gt 500MB -or $_.Extension -eq '.vhdx' } |
  Sort-Object Length -Descending | Select-Object -First 25 FullName, @{n='SizeGB';e={[math]::Round($_.Length/1GB,2)}}, LastWriteTime

# 5. Liệt kê Top 25 Phần mềm chiếm dung lượng lớn nhất (Đọc trực tiếp từ Registry Uninstall — cực nhanh & an toàn)
$uninstallPaths = @(
  'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*'
)
Get-ItemProperty $uninstallPaths -ErrorAction SilentlyContinue |
  Where-Object { $_.DisplayName -and $_.EstimatedSize } |
  Select-Object DisplayName, DisplayVersion, Publisher, InstallDate, @{n='EstimatedGB';e={[math]::Round($_.EstimatedSize/1MB, 2)}} |
  Sort-Object EstimatedGB -Descending | Select-Object -First 25 | Format-Table -AutoSize
