Install once, use forever.

A skill is a folder of instructions with ready-made scripts. The agent reads only what each step needs and runs the scripts instead of writing its own, so it uses less quota and makes fewer mistakes. Works with Claude Code, Codex, GitHub Copilot, Cursor, Gemini CLI, OpenCode and other Agent Skills agents.

  1. Download the skill (.zip) to your PC.
  2. Ask your agent to install it: copy the message below, replace the zip path, send it.
  3. Start a new session of the agent and send the opening message from Customise. Skills load when a session starts.

The selected report shows measured folder categories, completeness and uncertainty. Application data, virtual disks and personal files are not automatically junk. Choose simple or no HTML when you prefer it.

Install the skill from this zip: <path to the .zip>. Extract it to a temporary folder, then run install.ps1 inside it with: powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1. Tell me when done.

Prefer to do it yourself? Extract, then copy the syrin-clean folder into %USERPROFILE%\.claude\skills for Claude Code, or %USERPROFILE%\.agents\skills for the other agents.

The skill replies in the language you write in. A Vietnamese edition is on the Vietnamese page.

Optimisation mythsPopular tips that are useless or harmful
MythReality
Deleting Prefetch speeds up the PCWrong. It is tiny and only read when that app starts; deleting it makes the next launch slower.
SysMain must be off everywhereWrong for most PCs. It uses free RAM and releases it instantly.
/type reduced keeps Hibernate and saves spaceWrong. Reduced only supports Fast Startup; hibernation is gone.
-RestorePointType MODIFY_SETTINGS bypasses the 24-hour limitWrong. The limit comes from SystemRestorePointCreationFrequency; the skill sets it to 0 temporarily, restores it and verifies.
WinSxS is 20 GB, delete some of itMisread. Most of it is hard links shared with System32; measure with AnalyzeComponentStore.
Weekly registry cleaning makes Windows smootherMyth, high risk. Orphan keys cost nothing; a wrong deletion can break apps.
Turn off the pagefile with 16 to 32 GB RAMWrong. Games, compilers, AI tools and crash dumps need it; keep System Managed.
Ultimate/High Performance is always fasterNot really. On hybrid CPUs and laptops Balanced + Power Mode is usually as fast and cooler.
RAM boosters make the PC fasterWrong. Forcing RAM free makes Windows reload data from disk.
Turn off Defender, Update or VBS for speedBad trade. Tiny gains, large security risk; the skill reports status only.
Win32_Product or wmic to list softwareTrap. Win32_Product triggers MSI self-repair; wmic is removed from new Windows 11.
