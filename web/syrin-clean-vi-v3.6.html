Cài một lần, dùng mãi.

Skill là một thư mục hướng dẫn kèm script viết sẵn. Agent chỉ đọc phần cần cho từng bước và chạy script thay vì tự viết, nên ít tốn quota và ít lỗi hơn. Dùng được với Claude Code, Codex, GitHub Copilot, Cursor, Gemini CLI, OpenCode và các agent theo chuẩn Agent Skills.

  1. Tải Skill (.zip) về máy.
  2. Nhờ agent cài giúp: sao chép câu dưới đây, thay đường dẫn file zip rồi gửi.
  3. Mở phiên mới của agent và gửi câu mở đầu ở phần Tùy chỉnh. Skill chỉ được nạp khi bắt đầu phiên.

Báo cáo theo lựa chọn của bạn hiển thị nhóm dữ liệu đã đo, mức độ đầy đủ và phần chưa biết. Dữ liệu ứng dụng, máy ảo và file cá nhân không tự động thành rác. Có thể chọn bản đơn giản hoặc không tạo HTML.

Hãy cài skill từ file zip này: <đường dẫn file .zip>. Giải nén ra một thư mục tạm, rồi chạy install.ps1 bên trong bằng: powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1. Xong thì báo tôi.

Tự cài cũng được: giải nén, chép thư mục syrin-clean vào %USERPROFILE%\.claude\skills cho Claude Code, hoặc %USERPROFILE%\.agents\skills cho các agent khác.

Có bản hướng dẫn tiếng Anh; mức dùng token tùy agent và model, vẫn có thể trả lời tiếng Việt.

Ma trận thích ứng phần cứngAgent chọn cách làm theo đúng loại máy của bạn
Các mục dưới đây là kiến thức chẩn đoán, không phải tính năng tự chỉnh hệ thống. Thay đổi file dùng kế hoạch được duyệt; thao tác cấu hình và sửa chữa chưa hỗ trợ giữ ở dạng tư vấn.
Prompt bắt agent đo thật ở Giai đoạn 0 rồi rẽ nhánh. Một máy có thể thuộc nhiều nhánh cùng lúc (ví dụ Laptop + 16 GB + NVMe + Intel lai + Windows 11 Home).

Loại máy
PCSystemType, ChassisTypes, Win32_Battery		
              Desktop: có thể đề xuất powercfg /h off (lấy lại đúng dung lượng hiberfil.sys, đồng thời mất Fast Startup) hoặc /type reduced. Plan Balanced, High Performance chỉ khi đo thấy lợi.
              Laptop / 2-in-1 / Handheld: không tắt Hibernate. Lưu ý /type reduced cũng bỏ chế độ Ngủ đông, chỉ còn Fast Startup. Máy Modern Standby chỉnh qua Power Mode, tách cắm sạc/dùng pin, đo % chai pin.
              Máy ảo / Cloud PC: nhận qua Manufacturer/Model (Virtual, VMware, QEMU...), không qua HypervisorPresent. Bỏ qua nhiệt, SMART, BIOS, pin, driver GPU; nén ổ ảo từ phía máy chủ.

            
Dung lượng RAM
Win32_PhysicalMemory, Commit		
              ≤ 8 GB: khắt khe với Startup, trình duyệt chạy nền, Widgets, hiệu ứng. Pagefile System Managed trên SSD nhanh nhất. Commit thường trên 80% thì khuyên nâng RAM.
              12 – 16 GB: cắt Startup thừa, giữ SysMain, theo dõi Commit và Hard Page Faults khi đa nhiệm.
              ≥ 32 GB: không đổ lỗi cho hiệu ứng hay SysMain. Soi tiến trình bất thường, kênh đơn/đôi, tốc độ RAM (so ConfiguredClockSpeed với mã PartNumber, không chỉ với Speed).

            
Ổ hệ thống
Get-PhysicalDisk, Get-StorageReliabilityCounter		
              NVMe / SATA SSD: TRIM bật, lịch Optimize Drives chạy, giữ trống 15–20% và ≥ 30 GB, không defrag kiểu cũ. MediaType báo Unspecified thì suy luận từ BusType/model.
              HDD làm ổ C: nút cổ chai số 1. Giữ SysMain, giảm tác vụ nền ghi đĩa, phân tích phân mảnh, khuyên mạnh nâng SSD.
              Ổ nhỏ ≤ 128 GB / eMMC: ưu tiên di chuyển, Storage Sense, cân nhắc CompactOS. Nhiều ổ: dời game, cache Dev/AI, WSL, thư mục media sang ổ phụ thay vì xóa.

            
CPU
Win32_Processor, ProcessorInformation		
              Intel lai P/E-core (12th Gen+ / Core Ultra): Windows 11 + Balanced/Power Mode để Thread Director điều phối; không ép High/Ultimate Performance khi không đo được lợi.
              AMD Ryzen: chipset driver mới (dòng X3D cần chipset driver + Game Bar để điều phối nhân), Balanced; dọn C:\AMD sau mỗi lần cài Adrenalin.
              ARM64 (Snapdragon X...): driver chỉ từ Windows Update/OEM, ưu tiên app ARM64 gốc (app x64 chạy giả lập Prism tốn hơn), bỏ qua mọi mục XMP/NVIDIA/AMD.

            
GPU
Win32_VideoController		
              NVIDIA: dọn C:\NVIDIA và Downloader, đo DXCache/GLCache, HAGS khi driver hỗ trợ.
              AMD Radeon / Intel Arc & iGPU: đo DxCache/DxcCache/VkCache hoặc ShaderCache, kiểm tra ngày driver.
              Laptop GPU lai: đặt GPU hiệu năng cao cho game/app nặng trong Settings > Display > Graphics; kiểm tra sự kiện Display 4101 (driver GPU treo).

            
Hệ điều hành & quản lý
Build, Edition, PartOfDomain		
              Windows 10: đã hết hỗ trợ từ 14/10/2025, nhắc lên Windows 11 hoặc ESU. Windows 11 nhận theo build ≥ 22000, không theo ProductName.
              Home vs Pro/Enterprise: Home không có Hyper-V nên không có Optimize-VHD; dùng diskpart compact vdisk.
              Máy công ty (domain/Entra ID/Intune): chỉ báo cáo và dọn cache cá nhân; mọi thay đổi chính sách để bộ phận IT quyết.

1Quá tải app khởi động, dịch vụ và tác vụ nền (launcher, updater, chat, trình duyệt chạy ngầm, overlay)Đếm mục Run/RunOnce + StartupApproved, thư mục Startup, Scheduled Tasks Logon/Boot ngoài \Microsoft\, dịch vụ bên thứ ba Automatic; thời gian boot từ Event ID 100.Rất cao trên mọi máy, nhất là ≤ 16 GB RAM. Xem điều kiện hoàn tác của từng thao tác.

Windows thường không đọc được nhiệt độ CPU tin cậy, agent phải nói rõ khi không đo được.Cao nếu đang bị bóp xung.

            
6Thiếu RAM, tràn sang PagefileCommit / Commit Limit, PagesPersec (lớp PerfOS_Memory).Cao trên máy 4–8 GB. Nếu do phần cứng, agent khuyên nâng RAM thay vì "tweak".

8Windows Update tồn đọng, lỗi file hệ thống, Search Indexer kẹtCờ PendingReboot, lịch sử cập nhật, DISM /CheckHealth, kích thước chỉ mục tìm kiếm.Trung bình – Cao về độ ổn định, hết quạt rú vô cớ.

Lời đồnSự thật kỹ thuật & cách prompt xử lý

          
            
"Xóa Prefetch cho máy nhanh"Sai. Prefetch chỉ nặng vài chục MB và chỉ được đọc khi mở đúng app đó. Xóa đi làm lần mở app sau chậm hơn.

            
"Phải tắt SysMain trên mọi máy"Không đúng với đa số máy. SysMain dùng RAM trống để nạp sẵn app hay dùng và nhả ra ngay khi cần. Chỉ cân nhắc khi đo thấy chính nó gây 100% disk kéo dài.

            
"/type reduced là cách giữ Hibernate mà vẫn tiết kiệm dung lượng"Sai. Kiểu reduced chỉ đủ cho Fast Startup, chế độ Ngủ đông sẽ không còn. Trên laptop đây là đánh đổi thật, prompt bắt agent nói rõ.

            
"-RestorePointType MODIFY_SETTINGS vượt được giới hạn 1 điểm khôi phục/24h"Sai. Giới hạn do giá trị registry SystemRestorePointCreationFrequency quyết định. Prompt v3.0 tạm đặt giá trị này về 0, tạo điểm, trả lại như cũ và xác minh bằng Get-ComputerRestorePoint.

            
"Xóa Windows\Installer để lấy lại vài chục GB"Cực kỳ nguy hiểm. Các phần mềm cài bằng MSI (Office, Visual Studio, Adobe...) sẽ không cập nhật hay gỡ được nữa.

            
"WinSxS nặng 15–30 GB, phải xóa bớt"Hiểu nhầm. Phần lớn là hard link dùng chung với System32 nên Explorer đếm trùng. Đo thật bằng AnalyzeComponentStore, dọn bằng StartComponentCleanup.

            
"Dọn Registry hằng tuần giúp máy mượt"Huyền thoại, rủi ro cao. Khóa mồ côi chỉ vài KB, không làm chậm máy; xóa nhầm khóa COM/Shell/Driver có thể gây lỗi app hoặc màn hình xanh.

            
"Tắt Pagefile khi có 16–32 GB RAM"Sai. Nhiều game, trình biên dịch, công cụ AI và cơ chế ghi crash dump cần Pagefile. Đặt bằng 0 dễ gây văng app "Out of memory". Công thức "1,5 lần RAM" cũng đã lỗi thời, để System Managed là tốt nhất.

            
"Ultimate/High Performance luôn nhanh hơn Balanced"Không chắc. Trên CPU lai và laptop, Balanced + Power Mode thường cho kết quả tốt và mát hơn; plan cao chỉ làm máy nóng, tốn pin.

            
"RAM booster / app dọn RAM giúp máy nhanh"Sai. Ép nhả RAM khiến Windows phải nạp lại dữ liệu từ ổ đĩa, máy chậm hơn. RAM trống là RAM lãng phí.

            
"Tắt Defender / Windows Update / VBS cho nhẹ máy"Đánh đổi không đáng. Lợi ích rất nhỏ (VBS có thể ảnh hưởng vài % FPS trên một số game) trong khi rủi ro bảo mật lớn. Prompt chỉ báo cáo trạng thái, không tắt.

            
"Defrag SSD cho nhanh" / "Tweak TCP registry cho mạng nhanh"Sai. Windows tự TRIM SSD theo lịch; defrag kiểu cũ chỉ tốn tuổi thọ. Windows hiện đại tự điều chỉnh TCP, tweak tay dễ gây lỗi mạng.

            
"Dùng Win32_Product hoặc wmic để liệt kê phần mềm"Bẫy kỹ thuật. Win32_Product kích hoạt MSI tự sửa chữa toàn bộ gói; wmic đã bị gỡ khỏi Windows 11 bản mới. Dùng registry Uninstall và winget list.
